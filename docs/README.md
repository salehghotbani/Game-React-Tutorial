The main README and technical documentation default to English. Persian onboarding and contribution guides are linked above. Application language selection is independent of documentation language.

## Suggested first contribution

1. Run the project and finish its first lesson and exercise.
2. Read [development](DEVELOPMENT.md), [product scope](PRODUCT.md) and [architecture](ARCHITECTURE.md).
3. Find your change in the [source map](DEVELOPMENT.md#source-map) and read the neighboring tests.
4. Follow the [contribution workflow](../CONTRIBUTING.md), including checks and a focused pull request.

The repository's [development rules](../AGENTS.md) apply to implementation work. No database, Python environment, Docker service or API key is required for the current application.
